# El objetivo, en tus manos 🧮

Aplicación interactiva desarrollada en Python con [Streamlit](https://streamlit.io/) que permite realizar operaciones matemáticas básicas (sumar, restar, multiplicar y dividir) con una interfaz oscura y moderna.

## 🚀 Características
- **Operaciones soportadas**: Suma, Resta, Multiplicación y División.
- **Validación**: Protección contra errores de división por cero.
- **Diseño**: Interfaz moderna en modo oscuro, adaptada y personalizada.
- **Controles**: Botón para calcular y botón para limpiar y reiniciar los campos.

## 📦 Instalación y Ejecución

1. Clonar el repositorio:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd "PROGRAMA PRUEBA"
   ```

2. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```

3. Ejecutar la aplicación:
   ```bash
   streamlit run app.py
   ```
